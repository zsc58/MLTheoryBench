# Problem

## Hierarchical distribution

For each member of an asymptotic parameter sequence, let integers L,s,m,V be at least two, set d=s^L, and let delta in (0,1). At each depth 0,...,L the token vocabulary is [V]={1,...,V}. Assume m<=V^(s-1), so that the sampling procedure below is feasible.

Draw production rules independently at each level l=1,...,L as follows. For each a in [V], choose a uniformly random m-element subset of [V]^(s-1), independently across a. Its elements give the m candidate patches whose first token is a. Uniformly allocate all Vm candidate patches to Vm distinguishable slots, with m slots for each parent token in [V]. A parent may produce exactly its m assigned patches, each with probability 1/m. The resulting rules are fixed for all training and test examples and are not revealed to the learner.

An example is generated by drawing the root R uniformly from [V], setting Y=e_R in R^V, and expanding every token at depth l-1 into a length-s patch at depth l using its production law. Conditional on the parent tokens, all node expansions are independent. The learner observes only the depth-L leaf sequence X in [V]^d and Y; intermediate tokens are unobserved. The structural parameters L,s,m,V are known.

Let P_l be the set of possible depth-l patches. Every such patch has a unique parent. Two patches in P_l are called synonyms when they have the same parent. Write U_l for the first, meaning leftmost, depth-l patch of a generated example and define

q_mu^(l)=(Pr(R=r | U_l=mu))_(r=1)^V,   mu in P_l.

Let kappa>=1 be a non-degeneracy bound: Pr(U_l=mu)>=1/(kappa |P_l|) for every l and mu in P_l.

The asymptotic regime is

m,V=Theta(log d),   L=O(log d/log log d),

log^3(2/delta)=o(min(m,V)),

as d tends to infinity. The constants in Theta and O are fixed along the sequence. Define

K_rho=sqrt(m) 20^(-(L-1)/2).

## Learner and observations

Leaf tokens are represented by their one-hot vectors in R^V. For each level l, group the current token representations into disjoint consecutive length-s patches. For a concatenated representation h in R^(sV), use the random feature map

phi_l(h)=M_l^(-1/2)(cos(omega_(l,k)^T h), sin(omega_(l,k)^T h))_(k=1)^(M_l),

where the omega_(l,k) are independent Gaussian vectors with law N(0,sigma_l^(-2) I_(sV)). Feature draws are independent across levels and independent of the grammar and all example generation. The bandwidths sigma_l are positive.

A shared matrix W_l in R^(V by 2M_l) maps each feature vector x to W_l x. Its normalized output is

W_l x / (1^T W_l x),

and is used as the corresponding token representation at depth l-1. To define the algorithm on every random outcome, assign output zero if this denominator is zero. Let f(X) in R^V be the final depth-zero output.

Train levels in the order L,L-1,...,1. At stage l, freeze all already-trained levels, take N_l fresh independent examples from the fixed grammar, and use only the feature vector x_(l,i) of the first level-l patch computed from example i's observed leaves. Minimize the empirical ridge objective

L_l(W)=(1/(2N_l)) sum_(i=1)^(N_l) ||Y_i-W x_(l,i)||_2^2 + (lambda_l/2)||W||_F^2

by T_l full-gradient steps from W=0, with positive ridge strength lambda_l and step size eta_l. Stage datasets are mutually independent conditional on the grammar. All hyperparameters may depend on the displayed structural parameters, kappa, K_rho, and delta, but not on the hidden rules or latent tokens. Put N=sum_(l=1)^L N_l.

## Task

Prove that suitable choices of the bandwidths, ridge strengths, step sizes, sample counts, feature widths, and iteration counts have the following properties for all sufficiently large members of the stated parameter sequence.

With probability at least 1-delta over the grammar, random features, and training examples, simultaneously:

1. For every l and every nonsynonymous pair mu,mu' in P_l,

   ||q_mu^(l)-q_mu'^(l)||_2 >= (20m)^(-(l-1)/2) >= K_rho m^(-l/2).

2. All normalization denominators encountered when evaluating the trained network on any leaf sequence in the grammar's support are nonzero. For every such sequence X, whose top-level patch is mu,

   max_(r in [V]) |f(X)_r-q_mu^(1)(r)| < 1/2.

The choices must satisfy

N <= poly(kappa,m,V,s,L,log(1/delta)) K_rho^(-2)m^L,

and both max_l M_l and max_l T_l must be bounded by

poly(K_rho^(-1),kappa,V,s,L,log(1/delta),m^L).

Here each poly denotes a bound with universal constant coefficients and degree, independent of the grammar and parameter sequence. Conclude that argmax of f(X) recovers the root R, and hence Y, on an independent fresh example with probability at least 1-delta.
