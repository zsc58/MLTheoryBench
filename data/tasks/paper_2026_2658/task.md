# Problem

## Setup

There are K >= 2 agents, and all observations take values in a measurable space Z. Each agent a has a positive-unlabeled (PU) data set partitioned into K recipient-designated blocks B^(a->j), j=1,...,K. Block designations are fixed independently of observed values. The blocks within each agent are mutually independent, and the complete local data collections are mutually independent across agents. Each block at source a contains n_a labeled null reference observations and m_a unlabeled test observations, where n_a and m_a are finite nonnegative integers. Thus each block contains an equal share of that agent's reference and test observations.

For source a, fix an integer k_a with 0 <= k_a <= n_a. In each B^(a->j), the first k_a reference observations form the ordered labeled portion used for learning. The other n_a-k_a reference observations and all m_a test observations form the unlabeled portion. Let H^(a->j) denote this PU learning input: the ordered labeled portion together with the unordered collection of all observations in the unlabeled portion. The true-null and alternative test identities are not supplied to the learner.

For every agent a, the sequence of all its raw null observations, comprising its reference observations and truly null test observations across its blocks, is exchangeable conditional on all its alternative observations. The local score rule is invariant under every permutation of the unlabeled portion of its input, keeping the first k_a labeled observations fixed. Local score rules are deterministic measurable real-valued functions defined on the indicated inputs.

Agent j uses B^(j->j) for its local learning, calibration, and final test evaluation. Write ell_j=n_j-k_j, denote its calibration observations by C_1^(j),...,C_(ell_j)^(j), and denote its test observations by z_1^(j),...,z_(m_j)^(j). Let I_0^(j) subseteq {1,...,m_j} be its true-null test index set. The global true-null index set is the tagged set I_0={(j,i):1<=j<=K, i in I_0^(j)}.

A fixed deterministic learner A and a fixed deterministic quantizer q are used for remote models, with q composed with A measurable. The quantizer maps model parameters to a discrete parameter space. Let f be a fixed jointly measurable real-valued score-evaluation map. The local score of Agent j is g^(j)(z;H^(j->j)). For each a!=j, source a trains a distinct surrogate for recipient j using only B^(a->j), and sends the model

\[
F^{(a\to j)}(z)=f\bigl(z;q(A(H^{(a\to j)}))\bigr).
\]

Agent j forms the quantized composite score

\[
\widetilde S^{(j)}(z)=\max\left\{g^{(j)}(z;H^{(j\to j)}),\max_{a\ne j}F^{(a\to j)}(z)\right\}.
\]

For each j, these composite scores evaluated on the null and alternative observations in B^(j->j) are almost surely pairwise distinct. Define the empirical p-values by

\[
p_i^{(j)}=\frac{1+\sum_{r=1}^{\ell_j}{\bf1}\{\widetilde S^{(j)}(C_r^{(j)})\ge\widetilde S^{(j)}(z_i^{(j)})\}}{\ell_j+1},\qquad 1\le i\le m_j.
\]

Let P^(j) be the ordered vector of Agent j's p-values, let M=sum_j m_j, and let P be their concatenation in agent order. Its pooled multiset is denoted by mathcal P.

A measurable set D subseteq R^d is increasing if x in D and y>=x coordinatewise imply y in D. A random vector X in R^d is PRDS on a coordinate subset J if, for every increasing measurable D and every i in J, P(X in D | X_i=x) has a nondecreasing version as a function of x. For the finite-valued p-values here, this means nondecreasing on the support of X_i. A vector is exchangeable conditional on given random objects if its conditional law is invariant under every permutation of its coordinates. Conditioning on received random models means conditioning on the sigma-field generated by their evaluations.

Fix alpha in (0,1). FastLSU uses local p-value counts to compute the pooled Benjamini-Hochberg rejection set at level alpha. Explicitly, when M>0, order the pooled values as p_(1)<=...<=p_(M), let

\[
r_\star=\max\left(\{0\}\cup\{r\in\{1,\ldots,M\}:p_{(r)}\le\alpha r/M\}\right),
\]

and reject exactly those hypotheses with p_i^(j)<=alpha r_star/M. When M=0, no hypotheses are rejected. Let V^(j) and R^(j) be the numbers of false and total rejections at Agent j, respectively, and write a vee b=max{a,b}.

## Task

Prove that, for every agent j, the vector of quantized composite scores on its calibration observations and truly null test observations is exchangeable conditional on its alternative composite-score vector and the received models (F^(a->j))_(a!=j). Consequently, prove that each local p-value vector is PRDS on I_0^(j), that the concatenated global p-value vector is PRDS on I_0, and that FastLSU controls the global false discovery rate:

\[
\mathbb E\left[\frac{\sum_j V^{(j)}}{(\sum_j R^{(j)})\vee1}\right]\le\alpha.
\]
