# Problem

## Setup

Let S, A, and O be nonempty finite sets, and let d_theta, d_w, and d be positive integers. Fix feature maps f_p:S×A×S→R^{d_theta} and f_o:S×O→R^{d_w}, with every feature vector having Euclidean norm at most a finite B>=0. Define

P_theta(s'|s,a)=exp(<theta,f_p(s,a,s')>)/sum_{x in S}exp(<theta,f_p(s,a,x)>),

Phi_w(o|s)=exp(<w,f_o(s,o)>)/sum_{y in O}exp(<w,f_o(s,y)>).

The known probability distribution nu_0 on S satisfies 0<nu_min<=nu_0(s)<=nu_max<1 for every s. Fix a true parameter Theta*=(theta*,w*), a radius r_Theta>0, and a learned parameter Theta=(theta,w) in the closed Euclidean ball K={Theta':||Theta'-Theta*||_2<=r_Theta}. These parameters are fixed, not selected as functions of the trajectories or preference labels below. Write delta(theta)=||theta-theta*||_2 and delta(w)=||w-w*||_2.

Define

kappa_P=inf_{(theta',w') in K} min_{a in A, s,s' in S} sum_{x in S} min{P_theta'(x|s,a),P_theta'(x|s',a)},

kappa_Phi=inf_{(theta',w') in K} min_{s,s' in S} sum_{o in O} min{Phi_w'(o|s),Phi_w'(o|s')}.

Assume alpha=(1-kappa_P)(4-3kappa_Phi)<1.

For a prescribed action sequence, observations are generated from the true model as follows: s_0 has law nu_0, and at each time t the next state has conditional law P_theta*(·|s_t,a_t) and its observation o_{t+1} has conditional law Phi_w*(·|s_{t+1}). The actions are prescribed before these observations are generated. For any parameter vartheta=(theta',w'), define b_0^vartheta=nu_0 and, on this same action-observation history,

b_{t+1}^vartheta(s')=
Phi_w'(o_{t+1}|s') sum_{s in S}P_theta'(s'|s,a_t)b_t^vartheta(s)
/
[sum_{x in S}Phi_w'(o_{t+1}|x) sum_{s in S}P_theta'(x|s,a_t)b_t^vartheta(s)].

For probability vectors, ||b-b'||_TV=(1/2)sum_s|b(s)-b'(s)|.

Fix a reward feature map psi:S×A→R^d with ||psi(s,a)||_2<=B_r for a finite B_r>=0, and a true reward parameter mu* with ||mu*||_2<=r_mu, where 0<=r_mu<infinity. Let r(s,a)=<mu*,psi(s,a)> and bar psi(b,a)=sum_s b(s)psi(s,a).

Let N,T be positive integers. There are N independent preference comparisons. Each comparison contains two length-T logged trajectories, each having the true-model observation law just specified for its prescribed action sequence and common initial distribution nu_0. For comparison i and trajectory j in {1,2}, write its beliefs as b_{i,h}^{(j),vartheta} and its actions as a_{i,h}^{(j)}. Define

phi_i=sum_{h=0}^{T-1}bar psi(b_{i,h}^{(1),Theta*},a_{i,h}^{(1)})-sum_{h=0}^{T-1}bar psi(b_{i,h}^{(2),Theta*},a_{i,h}^{(2)}),

tilde phi_i=sum_{h=0}^{T-1}bar psi(b_{i,h}^{(1),Theta},a_{i,h}^{(1)})-sum_{h=0}^{T-1}bar psi(b_{i,h}^{(2),Theta},a_{i,h}^{(2)}).

The label y_i belongs to {0,1}, and conditional on the clean features the labels are independent with

P(y_i=1|phi_i)=sigma(<mu*,phi_i>), where sigma(z)=1/(1+exp(-z)).

Define Sigma=N^{-1}sum_i phi_i phi_i^T and tilde Sigma=N^{-1}sum_i tilde phi_i tilde phi_i^T. Let tilde mu be any minimizer over ||mu||_2<=r_mu of the unpenalized empirical negative log-likelihood

tilde L(mu)=-N^{-1}sum_{i=1}^N [y_i log sigma(<mu,tilde phi_i>)+(1-y_i)log(1-sigma(<mu,tilde phi_i>))].

For a positive-definite matrix M, write ||v||_M=sqrt(v^T M v), and let I denote the d-dimensional identity matrix.

Fix delta_b,delta_c in (0,1) and any fixed number c_zeta>1. Set

c=B(delta(w)+(3-2kappa_Phi)delta(theta)/2),

ell_b=log(2N/delta_b),

epsilon_b=2c/(1-alpha)+(2/(1-alpha))sqrt(2c ell_b/T)+[ell_b/(T(1-alpha))](4/3+2alpha/(1-alpha)),

rho=1/[2+exp(2TB_r r_mu)+exp(-2TB_r r_mu)].

If B_r epsilon_b>0, choose

zeta=c_zeta 16T^2B_r^2 epsilon_b(1+epsilon_b).

If B_r epsilon_b=0, choose any fixed zeta>0. Define

g_stat=[2sqrt(c_zeta)/(rho sqrt(N(c_zeta-1)))]sqrt(d log(1+4T^2B_r^2/(zeta d))+2log(1/delta_c)),

g_mis=[8TB_r epsilon_b/(rho sqrt(zeta))](1+TB_r r_mu/2).

## Task

Prove that, with probability at least 1-(delta_b+delta_c) over the logged observations and preference labels,

||tilde mu-mu*||_{tilde Sigma+zeta I}<=g_stat+g_mis+2r_mu sqrt(zeta).

Also prove that, for every prescribed action sequence and every integer t>=1,

E||b_t^Theta-b_t^Theta*||_TV<=[(1-alpha^t)/(1-alpha)]B(delta(w)+(3-2kappa_Phi)delta(theta)/2),

where the expectation is over observations generated by the true model with that action sequence. At t=0 the expected distance is zero.
