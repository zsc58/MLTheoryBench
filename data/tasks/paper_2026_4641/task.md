# Problem

## Setup

### Programs and widths

Fix a finite acyclic program whose variables are real scalars, real vectors, and an initial collection of real matrix parameters. Its initial scalars consist of scalar parameters, fixed scalar constants, and the coordinates of an external input \(\xi\in\mathbb R^{d_{\rm in}}\), where \(d_{\rm in}\) is fixed. Its initial vectors are vector parameters. Matrices are not generated by the program, but an initial matrix may be used repeatedly, including in both orientations.

Each vector coordinate axis has a width label \(u\) and a positive integer width \(n_u\). The program uses the following operations:

- **Avg.** From \(x\in\mathbb R^{n_u}\), form the scalar
  \[
  \operatorname{Avg}(x)=\frac1{n_u}\sum_{\alpha=1}^{n_u}x_\alpha.
  \]
- **MatMul.** For an initial matrix \(W\in\mathbb R^{n_{\rm out}\times n_{\rm in}}\), form either
  \[
  z=\frac1{n_{\rm in}}Wx\quad(x\in\mathbb R^{n_{\rm in}}),
  \qquad
  z=\frac1{n_{\rm out}}W^{\mathsf T}x\quad(x\in\mathbb R^{n_{\rm out}}).
  \]
- **OuterNonlin.** Choose a tuple of existing vectors \(x^1,\ldots,x^p\) on the same width axis of size \(d\), a tuple of existing scalars \(c=(c_1,\ldots,c_q)\), an integer \(r\geq0\), and a real-valued function \(\psi:\mathbb R^{p(r+1)+q}\to\mathbb R\). Writing \(X_\alpha=(x^1_\alpha,\ldots,x^p_\alpha)\), form \(z\in\mathbb R^d\) by
  \[
  z_\alpha=\frac1{d^r}\sum_{\beta_1,\ldots,\beta_r=1}^{d}
  \psi(X_\alpha;X_{\beta_1};\ldots;X_{\beta_r};c).
  \]
  When \(r=0\), this means \(z_\alpha=\psi(X_\alpha;c)\), with no summation.

The program, its operand choices, its integers \(r\), and its functions \(\psi\) are fixed as widths vary. Its scalar output is \(\operatorname{Avg}(v)\) for a specified generated or initial vector \(v\). Let \(f_n(\xi;\Theta)\) be this output, where \(\Theta\) denotes the collection of raw scalar, vector, and matrix parameters.

Choose integers \(k_u\geq1\) and set \(N_u=k_un_u\). All occurrences of a given width label use the same multiplier, and the chosen widths preserve every operand-dimension requirement of the program at both \(n\) and \(N\).

### Initialization and training data

Define coordinate replication by
\[
(\operatorname{Rep}_{k_u}x)_{(i,a)}=x_i,
\qquad 1\leq i\leq n_u,\quad1\leq a\leq k_u.
\]
For a matrix, define
\[
(\operatorname{Rep}_{k_{\rm out},k_{\rm in}}W)_{(i,a),(j,b)}=W_{ij}.
\]
Start the widened model by replicating every raw vector and matrix parameter in this way and copying every scalar parameter. Fixed scalar constants and external input coordinates are unchanged. Denote the resulting initial parameters by \(\Theta^{\rm up}_0\).

At each step \(t\geq0\), fix a finite batch of inputs \(\xi_{t,1},\ldots,\xi_{t,B_t}\), with \(B_t\geq1\), and a differentiable scalar loss \(\ell_t:\mathbb R^{B_t}\to\mathbb R\). Both models use this same batch and loss. Their training objectives are
\[
\mathcal L_{n,t}(\Theta)=\ell_t\big(f_n(\xi_{t,1};\Theta),\ldots,f_n(\xi_{t,B_t};\Theta)\big),
\]
and the corresponding expression at width \(N\). Thus the loss depends on parameters through the listed model outputs; weight decay is specified separately below. A random choice of batches or losses is understood through a common realization in the two runs.

Assume each function \(\psi\) is differentiable at every argument tuple evaluated during training in either run. All derivatives in the updates below are ordinary derivatives.

### Optimizer variables and updates

For each raw matrix \(W\in\mathbb R^{n_{\rm out}\times n_{\rm in}}\), the optimizer variable is
\[
A_W=\frac{W}{n_{\rm in}}.
\]
There is one such variable for each matrix parameter, regardless of how often the matrix is used or whether its transpose is used. Gradients with respect to \(A_W\) differentiate the entire objective with \(W=n_{\rm in}A_W\). After updating \(A_W\), set \(W=n_{\rm in}A_W\) for the next forward evaluation. At width \(N\), use \(A_W^{\rm up}=W^{\rm up}/N_{\rm in}\). Vector and scalar parameters themselves are their optimizer variables.

Let \(s\geq0\), fix a real degree \(m\), and use the same scalar maps
\[
Q_t:\mathbb R^{t+1}\times\mathbb R^s\longrightarrow\mathbb R
\]
in both models and entrywise on each optimizer variable. Their joint homogeneity means that, for every \(a>0\), every real gradient history \(g_0,\ldots,g_t\), and every \(\epsilon\in\mathbb R^s\),
\[
Q_t(ag_0,\ldots,ag_t;a\epsilon)
=a^mQ_t(g_0,\ldots,g_t;\epsilon).
\]
For an optimizer variable \(\theta\), let
\[
G_{\theta,t}=\nabla_\theta\mathcal L_{n,t}(\Theta_t).
\]
The updates use the gradient history beginning at step zero. In the **coupled** convention, entrywise,
\[
\theta_{t+1}=\theta_t-\gamma Q_t\big((G_{\theta,j}+\lambda\theta_j)_{j=0}^{t};\epsilon\big).
\]
In the **decoupled** convention, entrywise,
\[
\theta_{t+1}=(1-\gamma\lambda)\theta_t
-\gamma Q_t\big((G_{\theta,j})_{j=0}^{t};\epsilon\big).
\]
In particular, coupled decay for a matrix acts on \(A_W\), not on its raw matrix \(W\).

Choose width-independent base constants \(\bar\gamma,\bar\lambda,\bar\epsilon\). They may be specified per parameter tensor, but corresponding tensors in the two models have identical base constants. At width \(n\), use:

| Optimizer variable | \(\gamma\) | \(\epsilon\) | Coupled \(\lambda\) | Decoupled \(\lambda\) |
|---|---|---|---|---|
| \(A_W=W/n_{\rm in}\) | \(n_{\rm out}^{m}n_{\rm in}^{-1}\bar\gamma\) | \(n_{\rm out}^{-1}\bar\epsilon\) | \(n_{\rm in}n_{\rm out}^{-1}\bar\lambda\) | \(n_{\rm in}n_{\rm out}^{-m}\bar\lambda\) |
| Vector of width \(n_u\) | \(n_u^m\bar\gamma\) | \(n_u^{-1}\bar\epsilon\) | \(n_u^{-1}\bar\lambda\) | \(n_u^{-m}\bar\lambda\) |
| Scalar | \(\bar\gamma\) | \(\bar\epsilon\) | \(\bar\lambda\) | \(\bar\lambda\) |

At width \(N\), replace each width in this table by its widened value. Both runs use the same chosen decay convention.

## Task

Prove that for every program and initialization satisfying this setup, every input \(\xi\in\mathbb R^{d_{\rm in}}\), and every training step \(t\geq0\),
\[
f_n(\xi;\Theta_t)=f_N(\xi;\Theta_t^{\rm up}).
\]
Establish the claim for both weight-decay conventions.
