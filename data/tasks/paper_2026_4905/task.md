# Problem

## Setup

Let \(n\geq 1\) be an integer and let \(\mathcal D=\{x_1,\ldots,x_n\}\) be a finite population of prompt-response units. Each unit has a fixed latent binary preference \(r_i^*\in\{0,1\}\). All probabilities and expectations below are conditional on this fixed population and its latent preferences.

For each unit, a potential noisy binary annotation \(r_i\) is generated by a common binary channel: when \(r_i^*=1\), the probability that \(r_i=0\) is \(\rho_{01}\); when \(r_i^*=0\), the probability that \(r_i=1\) is \(\rho_{10}\). Here \(\rho_{01},\rho_{10}\in[0,1]\) and \(\rho_{01}+\rho_{10}<1\). An observability indicator \(o_i\in\{0,1\}\) satisfies \(\Pr(o_i=1\mid x_i)=p_i\), with \(p_i\in(0,1]\); conditional on \((x_i,r_i^*)\), observability and annotation noise are independent. Only units with \(o_i=1\) reveal \(r_i\).

For a real-valued reward predictor \(\hat r_\theta\) on \(\mathcal D\) and a binary-label loss \(\ell\), assume \(\ell(\hat r_\theta(x_i),t)\) is a finite real number for every \(i\) and \(t\in\{0,1\}\). Define
\[
L_{\mathrm{ideal}}=\frac1n\sum_{i=1}^n\ell(\hat r_\theta(x_i),r_i^*).
\]
Choose finite estimated noise rates \(\hat\rho_{01},\hat\rho_{10}\) with \(\hat d=1-\hat\rho_{01}-\hat\rho_{10}>0\). Define the noise-corrected surrogate values as the unique solution of
\[
(1-\hat\rho_{01})\widetilde\ell(\hat r,1)+\hat\rho_{01}\widetilde\ell(\hat r,0)=\ell(\hat r,1),
\]
\[
\hat\rho_{10}\widetilde\ell(\hat r,1)+(1-\hat\rho_{10})\widetilde\ell(\hat r,0)=\ell(\hat r,0).
\]
Write \(\widetilde\ell_i=\widetilde\ell(\hat r_\theta(x_i),r_i)\). Choose a propensity-estimation function \(\hat p_\phi:\mathcal D\to(0,\infty)\), write \(\hat p_i=\hat p_\phi(x_i)\), and choose finite imputation values \(\hat\varepsilon_i=\hat\varepsilon_\psi(x_i)\in\mathbb R\) for the conditional surrogate error.

The predictor, loss, noise-rate estimates, propensity-estimation function, and imputation function are fixed with respect to the annotation and observability randomness in this experiment; none is selected as a function of the realizations being averaged.

Define
\[
L_{\mathrm{IPS}}^*=\frac1n\sum_{i=1}^n\frac{o_i}{\hat p_i}\widetilde\ell_i,
\qquad
L_{\mathrm{DR}}^*=\frac1n\sum_{i=1}^n\left[\hat\varepsilon_i+\frac{o_i}{\hat p_i}(\widetilde\ell_i-\hat\varepsilon_i)\right].
\]
All expectations below are over the annotation and observability randomness, with the population and the fixed functions and estimates specified above held fixed.

## Task

Assume the noise rates are exact, \(\hat\rho_{01}=\rho_{01}\) and \(\hat\rho_{10}=\rho_{10}\). Prove in one integrated argument that:

1. \(L_{\mathrm{IPS}}^*\) is unbiased for \(L_{\mathrm{ideal}}\) when \(\hat p_i=p_i\) for every \(i\); and
2. \(L_{\mathrm{DR}}^*\) is unbiased for \(L_{\mathrm{ideal}}\) whenever either \(\hat p_i=p_i\) for every \(i\), or \(\hat\varepsilon_i=\mathbb E[\widetilde\ell_i\mid x_i,o_i=1]\) for every \(i\).
