# Problem

## Setup

Let `H` denote the quaternions. Write a quaternion matrix as

`Z = Z_0 + Z_1 i + Z_2 j + Z_3 k`,

where its four components are real matrices and `i^2 = j^2 = k^2 = ijk = -1`. For quaternion vectors, use the real inner product

`<q,k> = sum_l sum_{a=0}^3 q_a^(l) k_a^(l)`.

Fix positive integers `T`, `d_in`, and `d_h`. Let

`X = X_0 + X_1 i + X_2 j + X_3 k in H^{T x d_in}`

and let `W_Q,W_K in H^{d_in x d_h}`. Write the real components of either weight matrix `W` as `W_0,W_1,W_2,W_3`. Define the real block maps `B_{mu beta}(W)` by the following array, whose row is indexed by `mu` and column by `beta`:

```text
B(W) = [ W_0   -W_1   -W_2   -W_3
         W_1    W_0    W_3   -W_2
         W_2   -W_3    W_0    W_1
         W_3    W_2   -W_1    W_0 ].
```

Set `Phi_{mu beta}=B_{mu beta}(W_Q)` and `Psi_{nu gamma}=B_{nu gamma}(W_K)`. The quaternion linear projections `Q` and `K` therefore have real components

`Q_mu = sum_{beta=0}^3 X_beta Phi_{mu beta}` and
`K_nu = sum_{gamma=0}^3 X_gamma Psi_{nu gamma}`.

Define four real `T x T` component scores by

`C_0 = Q_0K_0^T - Q_1K_1^T - Q_2K_2^T - Q_3K_3^T`,

`C_1 = Q_0K_1^T + Q_1K_0^T + Q_2K_3^T - Q_3K_2^T`,

`C_2 = Q_0K_2^T - Q_1K_3^T + Q_2K_0^T + Q_3K_1^T`,

`C_3 = Q_0K_3^T + Q_1K_2^T - Q_2K_1^T + Q_3K_0^T`.

Also define the shared real score

`R = Q_0K_0^T + Q_1K_1^T + Q_2K_2^T + Q_3K_3^T`,

which is the matrix of real inner products between the rows of `Q` and `K`. Finally, define the projection-induced coefficient subspace

`U = span{Phi_{mu beta} Psi_{nu gamma}^T : mu,nu,beta,gamma in {0,1,2,3}}`,

a subspace of `R^{d_in x d_in}`. All scores here are considered before any nonlinear normalization.

## Task

Prove that the four component scores and the shared real score are generated by the common interaction subspace `U`: specifically, for every fixed pair `W_Q,W_K`, prove that there exist coefficient matrices `Lambda_alpha^{beta gamma}` and `M^{beta gamma}` in `U`, indexed by `alpha,beta,gamma in {0,1,2,3}` and determined solely by `W_Q,W_K`, such that the same coefficient matrices satisfy the following identities simultaneously for every input `X in H^{T x d_in}` and every `alpha in {0,1,2,3}`:

`C_alpha = sum_{beta,gamma=0}^3 X_beta Lambda_alpha^{beta gamma} X_gamma^T`,

and

`R = sum_{beta,gamma=0}^3 X_beta M^{beta gamma} X_gamma^T`.

Conclude that the shared real score introduces no bilinear coefficient interaction outside the projection-induced subspace already containing the coefficients of the component scores.
