# Problem

## Setup

Fix an instance \(x\) and a threshold \(\tau\in[0,1]\). Let
\[
p(x)=\mathbb P(Y=1\mid X=x),\qquad d(x)=\mathbf 1\{p(x)>\tau\}.
\]
A data-dependent model-selection procedure uses observed data \(D\), performance level \(\delta\), and a random inductive choice \(H\). It outputs a predictor \(\widehat p_H=S(H,D)\), with decision
\[
\widehat d_H(z)=\mathbf 1\{\widehat p_H(z)>\tau\}.
\]
The deployed model is generated by one draw of \(H\). A Rashomon sample \(RS_n\) consists of predictions from \(n\ge1\) independent draws \(H_1,\ldots,H_n\) from the same selection distribution (all conditional on the fixed \(D,\delta\)); assume there is no measurement error, so the decision-maker uses \(z=x\).

Define
\[
\pi_1=\mathbb P_H(\widehat d_H(x)=1),\qquad \pi_0=\mathbb P_H(\widehat d_H(x)=0),\qquad \theta=\min\{\pi_1,\pi_0\},
\]
and, from \(RS_n\),
\[
\widehat\theta_n=\min\left\{\frac1n\sum_{j=1}^n\mathbf 1\{\widehat d_{H_j}(x)=1\},\frac1n\sum_{j=1}^n\mathbf 1\{\widehat d_{H_j}(x)=0\}\right\}.
\]

## Task

Prove that
\[
\mathbb P_H\bigl(\widehat d_H(x)\ne d(x)\bigr)\ge \theta.
\]
Moreover, prove that as \(n\to\infty\), \(\widehat\theta_n\to\theta\) in probability, and that for every finite \(n\),
\[
\mathbb E[\widehat\theta_n]\le \theta.
\]
