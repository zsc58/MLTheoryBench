# Problem

## Setup

A hybrid zonotope in R^n is a set
\[
Z=\{G^c\xi^c+G^b\xi^b+c:\|\xi^c\|_\infty\le 1,\ \xi^b\in\{-1,1\}^{n_b},\ A^c\xi^c+A^b\xi^b=b\}.
\]
Continuous and binary generator columns are denoted by G^c and G^b. For HZs Z,Y and a matrix R, define generalized intersection
\[
Z\cap_R Y=\{z\in Z:Rz\in Y\},
\]
using its standard HZ representation. Affine images, coordinate projections, and constrained products C(Z,Y) of HZs with compatible equality-constraint blocks are HZ operations. In the constrained products used below, compatibility means that the operands carry the same leading equality-variable block; C stacks the represented variables while retaining the shared block and the remaining equality constraints, so its represented pairs are exactly those generated with the shared variables.

Consider an L-layer ReLU recurrent network
\[
h_t^{(0)}=x_t,\quad h_t^{(\ell)}=\operatorname{ReLU}(W_h^{(\ell)}h_{t-1}^{(\ell)}+W_x^{(\ell)}h_t^{(\ell-1)}+v_h^{(\ell)}),\quad
y_t=\operatorname{ReLU}(W_yh_t^{(L)}+v_y),
\]
with zero initial hidden states. In closed loop, x_{t+1}=y_t, where the hidden states and y_t are generated by the full displayed recurrence from x_1 and the preceding hidden states. Thus the closed-loop trajectory is defined operationally by the recurrence; no state-only map x_t\mapsto x_{t+1} is assumed. Let X be an HZ initial domain, X_1\subseteq X an HZ initial set, and T\subseteq X an HZ target. Define
\[
S_x(X,t)=\{(x_1,x_t):x_1\in X,\ \text{there exist hidden states and outputs satisfying the displayed recurrence and }x_{k+1}=y_k,\ k=1,\ldots,t-1\}.
\]
The exact reachable sets are R_t(X_1)=\{x_t:x_1\in X_1\text{ along the same recurrent trajectories}\} and P_t(T)=\{x_1\in X:x_t\in T\text{ along the same recurrent trajectories}\}.

For every preactivation coordinate used by the evaluator, fix a finite sound interval enclosure [alpha_i,beta_i] containing all values produced by that coordinate in the exact recursion and in every relaxed recursion under consideration. These same enclosures are used for every binary limit N_b. Define the exact symbolic evaluator recursively in the time index and network-layer index, without temporal unrolling: start from the HZ representation of X and the zero hidden state; at each displayed affine equation apply the corresponding affine HZ map, at each ReLU apply its exact graph HZ over the fixed sound interval, and whenever two HZ representations share equality variables, combine them with C while retaining those shared constraints. After the recursion reaches time t, retain the HZ representation of the ordered state pair (x_1,x_t); call this output S_{x,t}. Thus the evaluator is determined by the displayed recurrence, the fixed interval enclosures, and these operations.

For each ReLU coordinate over [alpha_i,beta_i], use its exact graph HZ in the nonpositive and nonnegative cases and the standard exact graph HZ or triangle HZ in the unstable case alpha_i<0<beta_i. For a fixed computed horizon t, let U_t be all unstable coordinates encountered in the recursion needed to produce S_{x,t}, including all required hidden-layer and output-layer coordinates at preceding times. Rank U_t by score s_i=-alpha_i beta_i/2 in descending order, using a fixed deterministic tie-break. Keeping the first N_b coordinates exact and using triangle graph HZs for the remainder defines the relaxed evaluator; denote its ordered state-pair output by \widetilde S_{x,t}^{N_b}. Let N_t=|U_t|. Assume N_b\in\mathbb Z_{\ge0}.

## Task

Prove that for every computed horizon t:

1. The exact evaluator satisfies S_{x,t}=S_x(X,t). Consequently,
\[
R_t(X_1)=[0\ I_n]\bigl(S_{x,t}\cap_{[I_n\ 0]}X_1\bigr),\qquad
P_t(T)=[I_n\ 0]\bigl(S_{x,t}\cap_{[0\ I_n]}T\bigr),
\]
so both exact reachable sets have HZ representations.

2. For every binary limit N_b, the relaxed evaluator satisfies
\[
S_x(X,t)\subseteq \widetilde S_{x,t}^{N_b},
\]
with equality whenever N_b\ge N_t. If 0\le N_b\le N_b', then
\[
\widetilde S_{x,t}^{N_b'}\subseteq \widetilde S_{x,t}^{N_b}.
\]
The corresponding relaxed reachable sets
\[
\widetilde R_t^{N_b}(X_1)=[0\ I_n]\bigl(\widetilde S_{x,t}^{N_b}\cap_{[I_n\ 0]}X_1\bigr),\qquad
\widetilde P_t^{N_b}(T)=[I_n\ 0]\bigl(\widetilde S_{x,t}^{N_b}\cap_{[0\ I_n]}T\bigr)
\]
contain R_t(X_1) and P_t(T), respectively, become exact when N_b\ge N_t, and tighten monotonically as N_b increases.
