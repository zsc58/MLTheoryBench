# Problem

## Setup

Let N >= 3 be an integer and let eta > 0. Choose and fix delta satisfying

`0 < delta < 1/(6N)`.

Let `q_i=(i-1)/(2(N-1))` for `i=1,...,N`. For `a,x in [0,1]`, define

`H_a(x)=max(0,1-|x-a|/delta)`.

For every continuous map `G:[0,1]^(N-2) -> [0,1]`, every `s=(s_2,...,s_{N-1}) in [0,1]^(N-2)`, and every `r in [2/3,1]`, define

`f^G_{s,r}(x) = r H_{q_1}(x) + sum_{i=2}^{N-1} s_i H_{q_i}(x) + G(s) H_r(x)`.

Let `F(G)` be the family of all these functions.

All learners are deterministic. Their query points and maps are fixed for the entire known task family; they may depend on that family and the prescribed budgets, but access the unknown function only through the evaluations specified below. Evaluations are exact and noise-free.

For query points `t_1,...,t_n`, write

`C_n(f;t_1,...,t_n)=((t_j,f(t_j)))_{j=1}^n`

for the ordered query-response transcript.

A fixed-query learner with query budget N consists of fixed points `t_1,...,t_N in [0,1]` and a final predictor

`P:([0,1] x R)^N x [0,1] -> R`.

Its output on a task f at a test point x is `P(C_N(f;t_1,...,t_N),x)`.

An adaptive-query learner with query budget N consists of an initial point `t_1 in [0,1]`, maps

`Q_n:([0,1] x R)^(n-1) -> [0,1]`, for `n=2,...,N`,

and a final predictor with the same domain as P above. Its queries satisfy

`t_n(f)=Q_n(C_{n-1}(f;t_1(f),...,t_{n-1}(f)))`,

where `t_1(f)=t_1`. Its output at x is `P(C_N(f;t_1(f),...,t_N(f)),x)`. Query maps do not receive the test point x as an input. Their stated codomain requirement applies on their entire stated domain, not only on transcripts attained by tasks in the family.

Write `C_N^L(f)` for the transcript generated by a learner L. Its worst-case uniform error on F(G) is

`E(L;F(G)) = sup_{f in F(G)} sup_{x in [0,1]} |P(C_N^L(f),x)-f(x)|`.

The optimal error in a specified regime is the infimum of this quantity over admissible learners in that regime.

A ReLU network is a finite composition of affine maps with the coordinatewise activation `sigma(u)=max(0,u)` between successive affine maps, and an affine output map. Its size is the total number of nonzero scalar entries in all affine matrices and bias vectors. Parameter magnitudes are unrestricted. Width and depth are finite but have no separate prescribed bounds.

In the unrestricted regime, the query maps and predictor may be arbitrary maps of their stated domains and codomains. In the ReLU regime with an integer weight budget `m >= 1`, each adaptive query map and the final predictor must be the restriction of a ReLU network of size at most m. For fixed-query learners this restriction applies to the final predictor. The final predictor is a single network acting jointly on the transcript and x. The budget is the size of the largest individual network, not the sum of their sizes.

A learner may use fewer than N queries only by adding unused queries.

## Task

Prove the following theorem. For every integer `N >= 3` and every `eta > 0`, there is an integer `m_0=m_0(N,eta)` such that, for every `delta` satisfying `0 < delta < 1/(6N)` and every integer `m >= m_0`, there exists a continuous map `G_m:[0,1]^(N-2) -> [0,1]` for which the family `F_{N,m}=F(G_m)`, formed with this delta, satisfies:

1. The optimal worst-case error of both unrestricted fixed-query and unrestricted adaptive-query learners with query budget N on F_{N,m} is zero.
2. Every fixed-query ReLU learner with query budget N and weight budget m has worst-case uniform error at least 1/2, whereas some adaptive-query ReLU learner with the same budgets has worst-case uniform error at most eta.

Consequently, whenever eta < 1/2, adaptive querying is strictly more powerful than fixed querying under the stated ReLU size constraint, although the two unrestricted models are equally powerful on this family.
