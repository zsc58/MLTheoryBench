# Problem

## Setup

Let \(\Theta\sim\operatorname{Bernoulli}(1/2)\). Inputs take values in \(\{0,1\}\), and the deployment distribution is \(\rho=\delta_0\). Conditional on \(\Theta\), a label at input \(0\) is \(\operatorname{Bernoulli}(1/2)\) and is independent of \(\Theta\); a label at input \(1\) equals \(\Theta\) almost surely. Conditional on \(\Theta\), all labels generated by these rules are independent. Let \(S_n\) be \(n\) iid labeled samples with inputs drawn from \(\rho\), and let the query input be \(1\), with corresponding label \(Y^\dagger\).

For an acquisition class \(\mathcal C\), which includes a null acquisition and may contain plans producing labeled observations \(Z^a_{1:k}\), define
\[
\mathsf E^{\mathcal C}_\infty
 =\inf_{a\in\mathcal C,\,k\geq 0}
 \mathbb E\!\left[I(\Theta;Y^\dagger\mid S_n,Z^a_{1:k})\right].
\]
Let \(\mathcal C_\rho\) be the class of plans that acquire any finite number of iid labeled samples from \(\rho\). Let \(\mathcal C_1\) be any acquisition class containing a plan that obtains one labeled observation at input \(1\).

Write
\[
\mathsf E_n=I(\Theta;Y^\dagger\mid S_n),\qquad
\mathsf A_n=H(Y^\dagger\mid\Theta,S_n).
\]
Call uncertainty deployment-sample-reducible when it can be eliminated by \(\mathcal C_\rho\), and mechanism-reducible when it can be eliminated by some other acquisition class.

## Task

Prove that, for every \(n\geq0\),
\[
\mathsf E_n=\log 2,
\qquad
\mathsf A_n=0,
\qquad
\mathsf E^{\mathcal C_\rho}_\infty=\log 2,
\qquad
\mathsf E^{\mathcal C_1}_\infty=0.
\]
Deduce that the usual aleatoric-versus-deployment-sample-reducible-epistemic dichotomy is not a partition: this construction has non-aleatoric uncertainty that is irreducible by arbitrarily much deployment-distribution data but reducible by a different acquisition mechanism.

Finally, prove that no binary classification can simultaneously impose both of the following conventions: (i) its epistemic amount is the mutual-information quantity \(I(\Theta;Y^\dagger\mid S_n)\), with aleatoric amount \(H(Y^\dagger\mid\Theta,S_n)\); and (ii) epistemic uncertainty is precisely uncertainty removable by additional deployment-distribution training data, with all non-epistemic uncertainty assigned to the aleatoric side.
