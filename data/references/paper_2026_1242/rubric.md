# Scoring Guide

- **0:** No correct idea or relevant valid method.
- **1-2:** Nontrivial relevant ideas, but no complete correct proof step or useful conclusion.
- **3-7:** Some correct core steps or conclusions, but important steps are missing.
- **8-9:** Complete and essentially correct, with only readily repairable errors or omitted cases.
- **10:** Fully correct.

# Core Steps

- **2 points:** Correctly relates permutation equivariance of the linear coupling to commutation of `M` with every permutation matrix.
- **2 points:** Proves sufficiency: `alpha I_C + beta 11^T` commutes with every permutation matrix, using invariance of the all-ones vector.
- **4 points:** Proves necessity by using transpositions (or an equivalent full-symmetry argument) to establish common diagonal and off-diagonal entries, including appropriate handling of the `C=1` case.
- **2 points:** Rewrites the matrix as `(d-o)I_C + o11^T` and derives the coordinate update as local self-coupling plus global pooled interaction.

# Evaluator Notes

Accept a complete valid alternative proof. Do not require the reference proof's incidental presentation choices.
