# Scoring Guide

- **0:** No correct idea or relevant valid method.
- **1-2:** Nontrivial relevant ideas, but no complete correct proof step or useful conclusion.
- **3-7:** Some correct core steps or conclusions, but important steps are missing.
- **8-9:** Complete and essentially correct, with only readily repairable errors or omitted cases.
- **10:** Fully correct.

# Core Steps

- **2 points:** Correctly derives the two-component Birkhoff-ratio formula for the embedded bicone from the order-based Hilbert metric.
- **3 points:** Establishes d_H >= max_i |log lambda_i| and hence d_AIRM^parallel <= sqrt(n)d_H, with the required eigenvalue/order cases justified.
- **2 points:** Proves sharpness of 1/sqrt(n) using a valid scalar boundary family and computes the limiting ratio.
- **3 points:** Constructs a valid family with d_AIRM^parallel -> 0 but d_H -> a positive limit, proving that no finite universal upper comparison exists.

# Evaluator Notes

Accept a complete valid alternative proof. Do not require the reference proof's incidental presentation choices.
