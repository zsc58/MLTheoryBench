# Scoring Guide

- **0:** No correct idea or relevant valid method.
- **1-2:** Nontrivial relevant ideas, but no complete correct proof step or useful conclusion.
- **3-7:** Some correct core steps or conclusions, but important steps are missing.
- **8-9:** Complete and essentially correct, with only readily repairable errors or omitted cases.
- **10:** Fully correct.

# Core Steps

- **2 points:** Correctly uses the adapted bounded observations, pre-start choice of test type and level, conditional advantages, and strong and weak null conditions.
- **3 points:** Establishes a nonnegative supermartingale and a conditional Ville bound for a strong-null false commitment. If null truth is treated pathwise, accounts for possible later null violations, for example by predictably truncating wealth before the first violation.
- **2 points:** Uses simultaneous conditional confidence-sequence coverage to show that a lower-bound crossing at a nonnegative margin under the weak null entails a coverage failure.
- **3 points:** Uses the fixed countable indexing, the tower property for random predictable levels, and the pathwise summable allocation to bound the probability of any false commitment throughout the adaptive run by \(\alpha\).

# Evaluator Notes

Accept any complete valid alternative proof. Do not require the reference proof's incidental presentation choices. Do not treat a pathwise null event alone as establishing that the unmodified wealth is a supermartingale under the unconditional law, or substitute a random assigned level for its expectation in an unconditional probability bound.
