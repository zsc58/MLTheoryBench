# Reference Proof

## Source-Contract Note

The simulator configuration, initial state, demand-rate sequence, and source lead-time parameters are fixed. Construction-time randomness in the demand-rate tensor is not averaged over in this chain. The only random inputs are the independent input pairs specified in the problem. Full lead-time vectors can be sampled whether or not each coordinate is subsequently used.

The source's defining algorithm takes the current time as an input and stores absolute due dates. Accordingly, the repaired notation is \(\Psi(t,x,y,\ell)\). This supplies an omitted deterministic argument; it does not change the algorithm or introduce additional random information. The fixed configuration assumptions are encapsulated in this deterministic update. Its being a well-defined measurable map into \(X\) is a primitive premise of the task, not an implementation-correctness conclusion to be proved.

## Proof Structure

1. Verify that each \(P_t\) is a measurable probability kernel.
2. Show recursively that the state is measurable with respect to the filtration generated by the initial state and past inputs.
3. Use independence of the next input pair to identify its averaged conditional transition law, first given the input filtration and then given the state history.
4. Construct and verify one transition kernel for the time-augmented process.

## Complete Proof

### Kernel Properties

The sets \(\mathcal Y\) and \(\mathcal L\) are countable. The prescribed Poisson masses and discretized-Gaussian masses are probability mass functions, so their finite products \(\mu_t\) and \(\nu_t\) are probability laws. For an empty source set, the lead-time space has one element and its mass is the empty product, equal to one.

For each fixed \(t\) and \(x\), \(P_t(x,\cdot)\) is a nonnegative countable mixture of point masses at \(\Psi(t,x,y,\ell)\). Thus it assigns zero to the empty set. For pairwise disjoint Borel sets \(A_j\), the identity
\[
\mathbf 1_{\cup_j A_j}(\Psi(t,x,y,\ell))
 =\sum_j\mathbf 1_{A_j}(\Psi(t,x,y,\ell))
\]
and interchange of nonnegative sums give countable additivity. Since the update takes values in \(X\),
\[
P_t(x,X)=\sum_y\sum_\ell\mu_t(y)\nu_t(\ell)=1.
\]
For each fixed Borel \(A\), every function \(x\mapsto\mathbf 1_A(\Psi(t,x,y,\ell))\) is measurable. Their nonnegative weighted countable sum is measurable. Therefore \(P_t\) is a Markov transition kernel.

### Recursive Measurability

Let
\[
\mathcal F_t=\sigma(x_0,y_0,L_0,\ldots,y_{t-1},L_{t-1}),
\qquad
\mathcal G_t=\sigma(x_0,\ldots,x_t).
\]
The initial state is fixed and hence \(\mathcal F_0\)-measurable. If \(x_t\) is \(\mathcal F_t\)-measurable, then \((x_t,y_t,L_t)\) is \(\mathcal F_{t+1}\)-measurable. Measurability of the update at the fixed index \(t\) gives
\[
x_{t+1}=\Psi(t,x_t,y_t,L_t)
\]
as an \(\mathcal F_{t+1}\)-measurable random variable. Induction establishes this for every time. Since the filtration is increasing, every \(x_j\) with \(j\leq t\) is \(\mathcal F_t\)-measurable, and consequently \(\mathcal G_t\subseteq\mathcal F_t\).

### Conditional Transition Law

The pair \((y_t,L_t)\) is independent of \(\mathcal F_t\), and its joint mass at \((y,\ell)\) is \(\mu_t(y)\nu_t(\ell)\).

Fix a Borel set \(A\subseteq X\). For each input value define the bounded \(\mathcal F_t\)-measurable random variable
\[
f_{y,\ell}=\mathbf 1_A(\Psi(t,x_t,y,\ell)).
\]
For every event \(D\in\mathcal F_t\), independence gives
\[
\mathbb E[\mathbf 1_D f_{y,\ell}
 \mathbf 1_{\{(y_t,L_t)=(y,\ell)\}}]
 =\mu_t(y)\nu_t(\ell)\mathbb E[\mathbf 1_D f_{y,\ell}].
\]
The independence factorization for bounded measurable variables follows first for simple \(\mathcal F_t\)-measurable variables and then by nonnegative approximation. Summing this equality over the countable input spaces, with nonnegative interchange, yields
\[
\mathbb E[\mathbf 1_D\mathbf 1_A(x_{t+1})]
 =\mathbb E[\mathbf 1_D P_t(x_t,A)].
\]
As \(P_t(x_t,A)\) is bounded and \(\mathcal F_t\)-measurable, this proves
\[
\mathbb P(x_{t+1}\in A\mid\mathcal F_t)
 =P_t(x_t,A)\quad\text{a.s.}
\]
Moreover, \(P_t(x_t,A)\) is \(\mathcal G_t\)-measurable. The same tested equality holds for every \(D\in\mathcal G_t\), because \(\mathcal G_t\subseteq\mathcal F_t\). Therefore
\[
\mathbb P(x_{t+1}\in A\mid x_0,\ldots,x_t)
 =P_t(x_t,A)\quad\text{a.s.}
\]
This is the required time-inhomogeneous Markov property. No moment condition is needed: every indicator and conditional expectation here is bounded.

### Time Augmentation

Equip \(\mathbb N_0\times X\) with the product sigma-algebra. For a measurable set \(B\) define
\[
\bar P((r,x),B)
 =\sum_y\sum_\ell
 \mathbf 1_B(r+1,\Psi(r,x,y,\ell))\mu_r(y)\nu_r(\ell).
\]
For fixed \((r,x)\), this is a probability measure by the same countable-mixture argument. For fixed \(B\), its restriction to each time slice \(\{r\}\times X\) is measurable in \(x\). Since the time coordinate is countable and discrete, the entire function \((r,x)\mapsto\bar P((r,x),B)\) is measurable. Hence \(\bar P\) is a transition kernel.

Let \(B_{t+1}=\{x:(t+1,x)\in B\}\), a measurable section. The history of \(Z_j=(j,x_j)\), \(0\leq j\leq t\), generates exactly \(\mathcal G_t\), since its time coordinates are deterministic. Thus
\[
\begin{aligned}
\mathbb P(Z_{t+1}\in B\mid Z_0,\ldots,Z_t)
 &=\mathbb P(x_{t+1}\in B_{t+1}\mid\mathcal G_t)\\
 &=P_t(x_t,B_{t+1})\\
 &=\bar P((t,x_t),B)\\
 &=\bar P(Z_t,B)
\end{aligned}
\quad\text{a.s.}
\]
The kernel \(\bar P\) is one fixed function of the augmented state, so \((Z_t)\) is time-homogeneous Markov.
