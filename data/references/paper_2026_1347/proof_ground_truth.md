# Reference Proof

Fix a computed horizon t. A closed-loop trajectory is generated from an initial state x_1 by the displayed recurrent equations, zero initial hidden states, and x_{k+1}=y_k. No state-only map from x_k to x_{k+1} is required. Let U_t be the finite ordered list of all unstable ReLU coordinates encountered in the recursion that produces the state-pair output at horizon t, including every hidden-layer and output-layer coordinate needed for times 1 through t-1. The ordering is fixed independently of N_b by decreasing score s_i=-alpha_i beta_i/2, with a fixed deterministic tie-break. Let N_t=|U_t|. Every interval [alpha_i,beta_i] is a common sound enclosure for the corresponding preactivation sets arising in the exact and relaxed recursions under consideration. Thus the same intervals and ordering are used for every N_b.

The essential induction invariant is fiberwise. Let q denote a feasible assignment to the shared leading equality-variable block inherited from X; q includes the continuous and binary latent variables that encode the common initial state and any equality constraints that must be retained by later constrained products. For every intermediate evaluator node A, write A[q] for the set of its visible variables feasible when this shared block is fixed to q. Every exact and relaxed node uses the same shared-block domain and retains q unchanged. If A and B are compatible operands, the fiber of their constrained product is the fiberwise join

C(A,B)[q] = { (a,b): a in A[q], b in B[q], and all remaining displayed compatibility constraints hold }.

Therefore, whenever A[q] subseteq A'[q] and B[q] subseteq B'[q] for every q, one has C(A,B)[q] subseteq C(A',B')[q] for every q. This is the monotonicity property required below; ordinary inclusion after projecting away q is not used as a substitute.

For the exact evaluator, prove by induction over the time/layer recursion that each hidden-state HZ fiber H_t^(ell)[q] represents exactly the hidden-state values generated by the initial-state latent assignment q. The base H_1^(0)=X is immediate, and the zero initial hidden states are fixed. An affine HZ map acts independently within each q-fiber and preserves equality variables. For an exact ReLU graph, the graph operation represents exactly the graph of ReLU over the preceding preactivation fiber because the interval used is a sound enclosure. Thus it neither adds nor removes feasible values in any fiber. At every recurrent/layer coupling, the two operands have the same shared block, and the constrained product joins their fibers at the same q. Hence the product represents exactly the hidden-state pairs generated from that one initial-state assignment. This proves the exact fiberwise invariant at every required time and layer.

The final constrained product between H_1^(0)=X and the output state at time t consequently represents exactly the x-coordinate state-pair set generated by the full recurrent trajectory:

S_x(X,t)={(x_1,x_t): x_1 in X and the hidden states, outputs, and states satisfy the displayed recurrence with x_{k+1}=y_k for k=1,...,t-1}.

Hence S_{x,t}=S_x(X,t). Intersecting this state-pair set with X_1 on the first coordinate retains exactly the trajectories whose initial state lies in X_1. Projection [0 I_n] then gives R_t(X_1). Similarly, intersecting with T on the second coordinate retains exactly the trajectories whose terminal state lies in T, and projection [I_n 0] gives P_t(T). Generalized intersection and affine projection preserve HZ representations, so both sets have exact HZ representations.

For the relaxed evaluator, define the corresponding relaxed fiber at every intermediate node using the same shared block q. The exact graph of every stable ReLU is unchanged. For each unstable coordinate and every fixed q, the exact ReLU graph is contained in its triangle graph over the common sound interval. Since the graph replacement retains the shared block, this is a fiberwise inclusion, not merely an inclusion after projection.

We now induct simultaneously through the relaxed recursion. Assume for every intermediate node A and every q that the exact fiber A_exact[q] is contained in the relaxed fiber A_relaxed[q]. Affine maps preserve this fiberwise inclusion. ReLU graph replacement preserves it by the exact-graph-subset-of-triangle relation at fixed q. If a constrained product joins two operands, the induction hypotheses give inclusion of both operand fibers at the same q; the fiberwise join property above then gives inclusion of the constrained-product fibers. Coordinate projections and generalized intersections with fixed sets preserve inclusion after the fiberwise relation has been established. Thus, at the final state-pair node, S_x(X,t) subseteq \widetilde S_{x,t}^{N_b}.

If N_b>=N_t, every coordinate in U_t is selected for exact treatment, so the relaxed and exact graph relations coincide at every q and the two recursions coincide: \widetilde S_{x,t}^{N_b}=S_x(X,t).

If 0<=N_b<=N_b', the fixed ranking makes the exact-coordinate set for N_b a subset of the exact-coordinate set for N_b'. For every unstable coordinate, the graph used at N_b' is therefore contained in the graph used at N_b, fiberwise for every q: exact graphs replace some triangle graphs and all other graphs are unchanged. Repeating the same fiberwise induction, including the constrained-product step, gives

\widetilde S_{x,t}^{N_b'} subseteq \widetilde S_{x,t}^{N_b}.

Finally, intersecting nested state-pair sets with the fixed first-coordinate set X_1 or second-coordinate set T and projecting preserves inclusion. Hence R_t(X_1) is contained in \widetilde R_t^{N_b}(X_1), P_t(T) is contained in \widetilde P_t^{N_b}(T), both relaxed sets are exact when N_b>=N_t, and both tighten monotonically as N_b increases.
